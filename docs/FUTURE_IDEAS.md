# Future Ideas

## Ear Training Cards (Next Up)
- Separate note type: "Ear Training"
- ~50 cards: 12 common intervals (unison, m2, M2, m3, M3, P4, P5, m6, M6, m7, M7, octave) from a few key roots
- Guitar-based (main instrument): plays reference note, then target note
- Front: see fretboard with reference note highlighted, hear both notes, "What interval is this?"
- Back: reveals target note position + interval name
- Audio: Web Audio oscillator, play note 1 for 0.5s, pause, play note 2 for 0.5s

## Standalone Trainer (Not Anki)
- Separate web app / HTML page for grinding through notes, intervals, scales at any pace
- No SRS scheduling — just rapid-fire practice, do as many as you want in one session
- Could cover:
  - Fretboard note identification (random note, name it fast)
  - Interval recognition by ear
  - Scale degree identification
  - Chord tone identification
- Timer/score tracking for gamification
- Good complement to Anki cards — Anki for spaced review, trainer for raw volume practice

## Possible Future Card Types
- **Rhythm reading**: see a rhythm pattern on staff, tap it out
- **Chord progression ear training**: hear a progression, identify the chords
- **Sight reading**: see notes on staff, play them on guitar (timed)
- **Key signature identification**: see sharps/flats, name the key
- **Circle of fifths**: interactive drill
